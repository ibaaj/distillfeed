Check arXiv reads every configured category and locally screens unseen papers. It does not call the ranking model.

Update remaining arXiv first checks the configured categories, then ranks every locally eligible paper that still lacks an AI score. It also repairs missing historical daily digests. Work is partitioned by stored publication day, and already AI-scored papers are reused instead of re-ranked.

This specialist recipe, shortlist and ntfy threshold are separate from ordinary feed summaries.

Open ArXiv module settings{% else %}

Check feeds reads the selected RSS and Atom documents and stores new feed entries. It does not open linked webpages or use AI.

Update this summary checks those feeds, then sends waiting titles and feed-provided descriptions to your configured model. Each entry is evaluated once after a successful response; DistillFeed then publishes one new summary for this exact selection.

Entries excluded by you are never selected. Sources set to “Only on request” are included when you update their own summary.

ArXiv module

A separate workflow retrieves selected arXiv categories, keeps every fetched paper, performs local screening, and invokes its specialist AI recipe only for a waiting announcement.

Module and daily digest

The local-score threshold decides which papers must receive an AI score. The ranking batch size only bounds each provider request; it never limits the total papers processed for a day.
